# 转盘平面标定（PX → MM）

把转盘工位上"物料中心"的像素坐标换成毫米，写给电控用。**只用现成工具**，不需要新脚本。

只标**一个平面**：物料顶面。转盘面的尺度不同（同一个物点在不同高度成像半径不同），
不能混用。上位流程见 [标定流程](标定流程.md) 第 8 节，这里是可照做的详细版。

---

## 0. 前置（不满足就别测，测了也白测）

| 项 | 要求 |
|---|---|
| 相机 | 高度、俯仰、镜头全部锁死；**这一轮标定期间不许动** |
| 对焦 | 对在**物料顶面**上（`focus_absolute`）。相机到顶面只有 6~7 cm，景深只有几毫米，对在转盘面上物料就是虚的 |
| 曝光 | 用固定档（补光用 `fill_light_locked`），不要自动曝光 |
| 颜色 | 物料色块必须能稳定识别，否则按 `d` 看不到 `materials[]` |

---

## 1. 要测的四个数

| # | 量 | 怎么测 | 期望 |
|---|---|---|---|
| M1 | 物料**顶面**直径 $D_{top}$ | 卡尺量圆台**上表面**的小圆（标称 φ30，底面是 φ50） | mm |
| M2 | 工作面**像素**直径 $d_{px}$ | 物料放在抓取位，启动 live 工具按 `d`，读 `materials[].equivalent_diameter` | px |
| M3 | 镜头到**转盘面** $H_{turn}$、镜头到**物料顶面** $H_{top}$ | 卷尺，从镜头前端量起 | mm |
| M4 | 原点像素 $(c_x,c_y)$ | 把物料摆到"**夹爪能垂直抓下去**"的位置，按 `d`，读 `materials[].center` | px |

M2/M4 用的工具：

```bash
python3 tools/test_turntable_color_live.py --task-code 234+123+432+231 --batch 1 --target 3
# 物料放到抓取位（M4）或标称位置（M2），按 d
```

读多帧取均值（`center_px` 会抖 ±1 px，约 0.07 mm）。M2 和 M4 最好在同一位置测，
一次 `d` 就能同时拿到 `equivalent_diameter` 和 `center`。

---

## 2. 计算

### 2.1 尺度

$$k = \frac{D_{top}}{d_{px}}\quad[\text{mm/px}]$$

### 2.2 平移（原点）

$$t_x = -k\,c_x,\qquad t_y = -k\,c_y$$

### 2.3 自检（两个都要过）

1. $H_{turn} - H_{top}$ **必须等于物料高度**（60 mm）。不等说明距离量错或量错了面。
2. 把物料横移 2~3 mm 再按一次 `d`：`equivalent_diameter` 变化应 <1%。
   变化很大说明物料离画面中心太远——此时物体会露出锥面，轮廓不再是顶面圆。

> **为什么轮廓是 φ30 顶面而不是 φ50 底面**：相机离顶面 $H_{top}$、离底面 $H_{turn}$，
> 底面半径 25 mm 的像按顶面平面折算只有 $25 \times H_{top}/H_{turn}$（实例中
> $25\times67/127 = 13.2$ mm），比顶面半径 15 mm 还小，所以外轮廓由**顶面**决定。
> 这是"相机离得近、物料又高"的透视结果，不是想当然。

---

## 3. 填写 `config/calibration.json`

```json
"TURNTABLE": {
  "calibrated": true,
  "homography_px_to_robot_mm": [
    [k, 0.0, t_x],
    [0.0, k, t_y],
    [0.0, 0.0, 1.0]
  ],
  "rmse_mm": null,
  "notice": "标定日期 / k / d_px / H_top / H_turn / 原点来源，改高度或对焦后必须重标"
}
```

- 含义：`x_mm = (x_px − c_x) × k`，`y_mm = (y_px − c_y) × k`，**x 向右、y 向下（图像方向）**。
- `camera_matrix` / `dist_coeffs` 保持 `null`，纯尺度标定用不到。
- `ROUGH` / `STORAGE` 高度不同，**保持 `false`**（它们仍是 `PX`）。
- `calibrated: true` 后，TURNTABLE 场景的 `unit` 才会变成 `MM`。

---

## 4. 验收

1. **平移法**：让电控沿 X 走 10.00 mm，再按 `d`，像素中心应移动 $10/k$ 像素。
   误差 <3% 合格。
2. **物体法**：把物料放在离抓取点 ±5 mm 处，比较 mm 输出与卡尺/塞尺读数。
3. 在画面左、中、右各测一次比例；若差别 >3%，说明广角畸变开始起作用，
   不能再用单一尺度（需要按位置修正或做畸变校正）。

---

## 5. 失效条件（务必写进 `notice`）

- 相机高度、俯仰、镜头对焦，**任何一项变动 → k 立刻失效，必须重标**。
  镜头到顶面从 67 mm 变成 60 mm，$k$ 就差 10%。
- 换物料高度（叠料）→ 工作面高度变了 → 重标。
- 物料顶面直径不是标称值时 $k$ 同比变（实测 30.5 mm 而非 30.0 → $k$ 差 3%）。

## 6. 换算备忘（实例，2026-09-20）

| 量 | 值 |
|---|---|
| $D_{top}$ | 30 mm（φ30 顶面） |
| $d_{px}$ | 409.5 px（抓取位 `equivalent_diameter`） |
| $k$ | **0.07326 mm/px**（13.65 px/mm） |
| $H_{top}$ / $H_{turn}$ | 67 mm / 127 mm（差 60 mm = 料高 ✔） |
| $(c_x, c_y)$ | (637.7, 356.8) = 夹爪对准位 |
| $t_x, t_y$ | −46.718, −26.146 |
| 1 px / 10 px / 100 px | 0.073 / 0.73 / 7.33 mm |

**别指望这个标定提升判色准确度**：颜色准不准由颜色标定和光照决定，这里只管单位。

## 7. 打开 MM 之后要跟着改的参数

| 参数 | 原因 |
|---|---|
| `runtime.stable_spread_mm` | 打开 MM 后它才生效。若沿用 2.0，稳定性门限从 `stable_spread_px=4.0`（=0.29 mm）被放宽到 2 mm，建议收到 **0.3~0.5** |
| `scenes.*.geometry.min_area/max_area` | 仍是像素单位，按 `equivalent_diameter` 的实测值定（工具里的 `recommended_area`） |
| 电控侧 | 输出是**画面方向**的 mm（相机装在末端、与夹爪同轴，画面方向就是末端方向），电控按这个方向动作即可 |
