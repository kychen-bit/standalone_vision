# 转盘颜色识别与推断测试

## 职责划分

算法端识别当前位置的实际颜色和中心坐标。电控端负责移动到下一个观察位置、
等待转盘、执行抓取，并根据本轮三个候选颜色完成第三个颜色的推断。推断依赖
机械臂实际到达了哪个观察位置，因此放在电控状态机中更可靠。

已实现（协议文档 3.7 / 4.4）：

```text
MCU -> Jetson: REQ,<seq>,CLASSIFY,TURNTABLE,<本轮颜色1>,<颜色2>,<颜色3>
Jetson -> MCU: ALIGN_READY,<seq>,CLASSIFY,<实际颜色>,<x>,<y>,0.000,<unit>,<confidence>,<stable_frames>
```

回复复用 `ALIGN_READY`，第 3 字段就是实际颜色号；不需要 `EXEC`，电控用完发 `DONE`。

原有 `REQ,<seq>,PICK,TURNTABLE,<目标颜色>` 和 `GRASP_READY` 保留，用于目标
已经确定后的最终稳定检查和抓取许可。

## 无电控算法测试

下面的例子表示本轮有红、蓝、黑，目标是蓝；先看到红，再看到黑，于是推断
剩余物料为蓝，并输出返回起点等待目标的决策：

```bash
python3 tools/simulate_turntable_pick_strategy.py \
  --target 3 \
  --round-colors 1 3 5 \
  --observed-order 1 5
```

目标在第一个或第二个位置时：

```bash
python3 tools/simulate_turntable_pick_strategy.py --target 3 --round-colors 1 3 5 --observed-order 3
python3 tools/simulate_turntable_pick_strategy.py --target 3 --round-colors 1 3 5 --observed-order 1 3
```

测试会经过真实 HSV 检测器、全颜色分类、中心计算和推断状态机，但画面是程序
生成的，因此只验证算法流程，不代表真实物料颜色阈值已经可靠。

## 真实摄像头识别效果测试

后台比赛服务会占用摄像头，测试前先停止，测试结束后再启动：

```bash
sudo systemctl stop standalone-vision.service
```

任务码 `156+123+516+231` 的第一轮颜色依次是 `1、5、6`。测试第一轮第一个
目标红色：

```bash
python3 tools/test_turntable_color_live.py \
  --task-code 156+123+516+231 \
  --batch 1 \
  --target 1
```

也可以手工给出本轮3种颜色：

```bash
python3 tools/test_turntable_color_live.py \
  --round-colors 1 5 6 \
  --target 5
```

检查全部6种颜色、当前目标为蓝色：

```bash
python3 tools/test_turntable_color_live.py --all-colors --target 3
```

程序检查本轮全部3种颜色，并用黄色标出其他已识别颜色。当前目标使用绿色标记，
同时输出目标中心和相对基准点的差值：

```text
target_center_px: [x, y]
target_delta_px: [dx, dy]
```

默认基准点是画面中心 `(640,360)`。实际抓取基准不在画面中心时使用
`--reference-x`、`--reference-y` 修改。按 `q` 或 `Esc` 结束。纯终端测试增加
`--headless`。结束后恢复后台服务：

窗口还会显示采集 FPS、算法 FPS、检测耗时、曝光、焦距、白平衡、三个自动档
状态、任务码、本轮颜色和当前识别颜色。移动鼠标可查看附近区域的 BGR 中位数及
HSV 的 5%、50%、95% 分位值。

该调试程序默认使用 `gstreamer_nv`，一次性协商 DECXIN 的
`1280x720 MJPG 60fps` 并使用 Jetson 硬件解码。首次建立管线可能需要约10秒，
看到 `Opening in BLOCKING MODE` 时继续等待，不要在初始化过程中按 `Ctrl+C`。
仅在排查采集后端时使用 `--camera-backend opencv_v4l2`。

```bash
sudo systemctl start standalone-vision.service
```
