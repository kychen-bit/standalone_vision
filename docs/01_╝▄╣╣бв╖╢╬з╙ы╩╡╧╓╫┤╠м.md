# 独立视觉项目架构、范围与实现状态

## 1. 文档目的

本项目用于视觉部分的独立开发和分板测试。它解决的是“图像中有什么、目标在哪里、结果是否稳定”，不负责导航、底盘运动、机械臂关节控制和夹爪动作。

必须区分以下三个层次：

1. **单帧检测**：在一张图中找到目标；
2. **多帧确认**：连续多帧目标一致、位置抖动足够小，输出 `STABLE`；
3. **抓取流程**：控制机械臂接近、对准、下降、闭合夹爪并确认成功。

当前独立项目已经实现前两个层次，没有实现第三个层次。`STABLE` 只表示视觉结果稳定，不表示物料已经抓起。

## 2. 硬件分工

| 硬件 | 当前视觉职责 | 不负责的内容 |
|---|---|---|
| MaixCAM Pro | 前视任务二维码识别、格式校验、连续帧确认 | 物料、圆环、转盘、抓取控制 |
| Jetson Nano + OG05B10 | 六色物料、圆环、工位、转盘、码垛目标识别 | 电机脉冲、机械臂关节闭环、夹爪动作 |
| 电控 | 当前独立项目不依赖电控 | 后续负责安全执行运动与反馈动作结果 |

相机安装在夹爪末端，属于眼在手上的安装方式。相机随夹爪移动，所以固定平面标定只在“相同相机姿态、相同相机高度、相同目标平面”下有效。

## 3. Module与interface

视觉核心的外部 interface 是：

```text
detect(frame, mode, args) -> Measurement | None
```

- `frame`：OpenCV BGR图像；
- `mode`：`COLOR`、`RING`、`STACK`、`STATION` 或 `TURNTABLE`；
- `args`：模式所需的目标编号和场景；
- 返回 `Measurement`：检测成功；
- 返回 `None`：本帧未检测到满足条件的目标；
- 配置错误使用异常表达，不能伪装成“未检测到”。

`Measurement` 字段：

| 字段 | 含义 |
|---|---|
| `kind` | 检测类型，例如 `COLOR`、`RING` |
| `target_id` | 颜色号、圆环号或场景号 |
| `x, y` | 目标中心坐标 |
| `yaw` | 工位偏航角，普通目标通常为0 |
| `confidence` | 0～1的几何质量分数，不是训练模型概率 |
| `unit` | `PX`或`MM` |
| `residual` | 多圆环工位拟合残差 |

多帧 interface 是：

```text
session.update(frame) -> measurement, stable_result, stable_count
```

相机、保存图片、窗口显示、控制台JSON和串口都是 adapter。测试可以给检测 module 传入内存图片，不需要创建相机或串口对象。

## 4. 数据流

```text
相机或保存图片
       ↓
畸变校正（有内参时）
       ↓
指定模式的单帧检测
       ↓
Measurement / None
       ↓
多帧稳定窗口
       ↓
TRACKING / STABLE / NOT_FOUND
       ↓
屏幕、JSON或可选串口输出
```

检测 module 不知道电机是否在运动，也不主动控制转盘或夹爪。这条 seam 使识别可以在没有电控的阶段先独立验证。

## 5. 当前实现状态

| 能力 | 状态 | 说明 |
|---|---|---|
| Maix任务二维码检测 | 已实现 | 校验四组三位任务码，连续4帧确认 |
| 二维码任务计划解析 | 未放入独立项目 | 当前只输出完整任务字符串，正式上位机再解析顺序 |
| 六色指定目标检测 | 已实现 | 输入目标颜色号，寻找该颜色；不是一次性六分类 |
| 任意当前物料颜色分类 | 未实现 | 如有需要可增加 `CLASSIFY_COLOR`，但原料等待策略不依赖它 |
| 转盘外圆检测 | 已实现 | 输出圆心，不能仅凭圆形外沿得到偏航角 |
| 转盘抓取窗口判定 | 未实现完整自动许可 | 当前可把 `object_roi` 缩成窗口测试，但没有独立内安全区和速度字段 |
| 单圆环识别 | 已实现 | 在预配置编号ROI中做霍夫圆检测 |
| 圆环数字OCR | 未实现 | 当前编号来自固定ROI，不读取环内数字 |
| 三圆环工位位姿 | 已实现 | 多环中心拟合平移和偏航并检查残差 |
| 码垛目标 | 已实现 | 在指定圆环ROI内找第一批同色物料中心 |
| 动态视觉伺服 | 未实现 | 当前不会在机械臂运动期间连续输出速度控制量 |
| 抓取成功判断 | 未实现 | 需要夹爪、电流、限位或其他电控反馈 |

## 6. 坐标与标定约束

未标定时：

```text
unit = PX
x, y = 图像像素坐标
```

完成固定平面单应性标定后：

```text
unit = MM
x, y = 配置中机器人平面坐标
```

以下情况不能共用同一个单应矩阵：

- 相机观察高度变化；
- 夹爪末端角度变化；
- 原料转盘、粗加工台、暂存台高度不同；
- 相机支架被碰撞后发生位移。

原料区、粗加工区、暂存区必须分别标定。眼在手上动态下降过程中如要持续换算毫米，需要高度相关标定或手眼标定；第一版建议在固定观察高度完成XY对准，再垂直下降。

## 7. 正式系统以后如何接入

推荐保持以下职责：

```text
视觉识别：目标位置、置信度、稳定/丢失
上位机任务层：当前要找哪种颜色、何时开始/取消识别
视觉伺服层：把目标误差转换为有界XY修正量（后续）
电控：安全执行运动、Z轴和夹爪、超时停止、返回完成结果
```

正式系统入口可以复用检测 module，但不能同时运行独立测试入口，否则两个进程会争抢同一相机。
