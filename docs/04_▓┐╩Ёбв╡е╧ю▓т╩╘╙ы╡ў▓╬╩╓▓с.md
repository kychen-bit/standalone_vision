# 部署、单项测试与调参手册

> 历史文档：旧 Lab 原型和动态 ROI 调试方式不再参与默认颜色流程。当前颜色命令与参数只以
> 根目录 `JETSON_RECOGNITION_TEST_GUIDE.md` 为准。

## 1. 推荐测试顺序

```text
无硬件自动测试
→ 保存图片单帧检测
→ Jetson只接OG05B10实时测试
→ MaixCAM Pro单板二维码测试
→ 各自可选串口发送测试
→ Jetson与Maix串口联调
→ 最后接电控与抓取动作
```

不要跳过保存图片测试直接调整整机。保存原始帧可以区分“算法错误”和“机械位置不正确”。

## 2. Jetson环境

Jetson Nano优先使用JetPack自带OpenCV：

```bash
cd standalone_vision
sudo apt update
sudo apt install -y python3-opencv python3-numpy python3-pip v4l-utils
python3 -m pip install --user -r requirements-jetson.txt
```

确认：

```bash
python3 -c "import cv2, numpy; print(cv2.__version__, numpy.__version__)"
v4l2-ctl --list-devices
ls -l /dev/v4l/by-id/
```

配置中应使用 `/dev/v4l/by-id/...` 稳定设备名。

## 3. 无硬件自动测试

```bash
python3 -m unittest discover -s tests -v
python3 -m compileall -q jetson_recognition maixcam_pro tests
```

自动测试不打开相机和串口，验证：

- 单帧检测 interface；
- 多帧稳定窗口；
- 合成红色物料检测；
- 串口CRC编码。

它不能替代实拍数据测试。

## 4. 实拍数据目录建议

建议在Jetson创建不提交代码仓库的大容量数据目录：

```text
samples/
├─ qr/
│  ├─ valid/
│  └─ invalid/
├─ color/
│  ├─ red/
│  ├─ yellow/
│  ├─ blue/
│  ├─ green/
│  ├─ black/
│  ├─ light_blue/
│  └─ negative/
├─ ring/
├─ station/
├─ turntable/
└─ stack/
```

每种条件至少保存：

- 正常光照；
- 强光；
- 阴影；
- 电机运行振动；
- 转盘运动和停留；
- 目标位于ROI中心与边缘；
- 部分遮挡；
- 无目标负样本。

原图不能只保存识别成功的帧，否则无法统计误报率。

## 5. 单图命令

颜色：

```bash
python3 -m jetson_recognition.run image samples/color/red/001.jpg \
  --mode COLOR --scene ROUGH --target 1 --show
```

圆环：

```bash
python3 -m jetson_recognition.run image samples/ring/001.jpg \
  --mode RING --scene ROUGH --target 2 --show
```

工位：

```bash
python3 -m jetson_recognition.run image samples/station/001.jpg \
  --mode STATION --scene ROUGH --show
```

转盘：

```bash
python3 -m jetson_recognition.run image samples/turntable/001.jpg \
  --mode TURNTABLE --scene TURNTABLE --show
```

码垛目标：

```bash
python3 -m jetson_recognition.run image samples/stack/001.jpg \
  --mode STACK --scene STORAGE --target 1 --ring 2 --show
```

无桌面环境用 `--save result.jpg`，不要使用 `--show`。

## 6. 实时命令

```bash
python3 -m jetson_recognition.run live \
  --mode COLOR --scene TURNTABLE --target 1 \
  --camera /dev/video0
```

SSH模式：

```bash
python3 -m jetson_recognition.run live \
  --mode COLOR --scene TURNTABLE --target 1 \
  --camera /dev/video0 --headless
```

串口选项必须位于 `live` 前：

```bash
python3 -m jetson_recognition.run \
  --serial /dev/ttyUSB0 --baud 115200 \
  live --mode COLOR --scene TURNTABLE --target 1 --headless
```

## 7. 调参顺序

必须按下面顺序调整，避免多个变量一起变化：

### 7.1 固定机械和光学条件

- 固定相机支架；
- 确定观察高度与夹爪姿态；
- 调整焦距；
- 锁定分辨率和帧率；
- 尽量锁定曝光、增益和白平衡；
- 确认MJPG输出稳定且无严重掉帧。

### 7.2 调ROI

先让ROI只覆盖可能出现目标的区域。ROI过大会增加背景误报，过小会截断目标。

原料区至少区分：

- 转盘外圆ROI；
- 物料搜索ROI；
- 正式抓取所需的内部安全窗口（待实现）。

### 7.3 采样颜色原型

默认颜色算法使用公共彩色候选条件和Lab原型竞争，不再逐色手调HSV上下限。相机、补光和曝光
固定后，依次运行 `tools/calibrate_color_prototype.py --target 1..6`；彩色目标自动写入Lab原型，
黑色自动写入L/V上限。不要只拿一块物料、一种姿态采集最终参数，详细流程见根目录
`JETSON_RECOGNITION_TEST_GUIDE.md`。

### 7.4 调轮廓面积

依次调整：

- `min_area_px`；
- `max_area_px`；
- 形态学核尺寸。

先看掩膜是否正确，再看轮廓过滤；掩膜本身错误时继续调面积没有意义。
当前目标只确定颜色而不确定形状，所以 `min_aspect`、`min_fill`、`min_solidity` 均保持0。
只有赛场实物明确具有固定形状时才启用，不能用它们压制颜色误报。

### 7.5 调霍夫圆

先测量实拍圆环像素半径，再设置半径范围。然后调边缘阈值和累加器阈值。半径范围过宽会把物料轮廓、螺钉、台面纹理作为候选圆。

### 7.6 调稳定窗口

最后才调整：

- `stable_frames`；
- `stable_spread_px/mm`；
- `min_confidence`；
- `reset_after_misses`。

稳定帧太少会在运动中误触发，太多会错过转盘短暂停留。

## 8. 建议记录的指标

| 指标 | 计算方式 |
|---|---|
| 单帧召回率 | 有目标帧中正确检测帧数/有目标帧数 |
| 单帧误报率 | 无目标帧中错误输出帧数/无目标帧数 |
| 稳定结果正确率 | 所有 `STABLE` 中目标正确的比例 |
| 稳定延迟 | 目标停止到输出 `STABLE` 的时间 |
| 坐标抖动 | 静止目标连续坐标的标准差或极差 |
| 丢失恢复时间 | 目标离开后清空旧状态所需时间 |
| 帧率 | 实际处理帧数/秒 |

初始验收建议：

- 六种颜色分别测试，不只计算总准确率；
- 负样本不允许输出错误 `STABLE`；
- 静止目标坐标抖动应明显小于抓取容差；
- 运动物料不应在抓取窗口外输出抓取许可；
- 转盘停留后应在停留时间内完成稳定确认。

具体阈值必须根据夹爪容差和实机停留时间确定，不能只在电脑上拍脑袋指定。

## 9. MaixCAM Pro测试

默认：

```python
DISPLAY_ENABLED = True
SERIAL_ENABLED = False
```

MaixVision运行 `main.py` 后依次测试：

1. 合法任务码；
2. 格式错误二维码；
3. 二维码快速移动；
4. 距离变化；
5. 倾斜观察；
6. 强反光和阴影；
7. 二维码离开后再次进入。

只有控制台稳定输出 `QR_STABLE` 后，才打开串口。

## 10. 故障定位表

| 现象 | 优先检查 |
|---|---|
| 相机打不开 | 设备名、权限、是否被其他进程占用、V4L2格式 |
| 图像尺寸异常 | 配置分辨率和相机实际输出 |
| 所有颜色都检测不到 | ROI、曝光、BGR/HSV转换、最小面积 |
| 黑色大量误报 | 阴影、亮度阈值、ROI和背景、曝光锁定 |
| 蓝色/浅蓝混淆 | 饱和度和亮度范围、白平衡、实物色差 |
| 圆环误检很多 | 半径范围、ROI、霍夫阈值、物料遮挡 |
| 有单帧结果但不STABLE | 坐标抖动、转盘仍运动、置信度、稳定帧数 |
| 输出PX而不是MM | 对应场景尚未完成平面标定 |
| 串口没有输出 | 是否显式开启串口、设备名、波特率、TX/RX交叉、共地、3.3V电平 |
