# 赛前相机调参简明指南

顺序：**固定相机、真实物料和补光 → 调相机并保存 → 调 HSV**。
以下命令在项目根目录执行。自动锁参前关闭其他取流程序；手动调参时只保留一个预览程序。

## 1. 只关注这几个参数

修改位置：`config/jetson.json → camera.v4l2_control_profiles.competition_locked`。
默认活动档为 `camera.v4l2_control_profile`。当前档含 `_replace_base: true`，只改基础
`camera.v4l2_controls` 不生效。JSON 修改后需重启程序；后台 `v4l2-ctl` 设置会直接影响设备。

| 参数 | 调整方法 |
|---|---|
| `focus_absolute` 对焦位置 | 关闭自动对焦，在实际工作面放小字或清晰边缘。偏差大时以 50～100 粗调，找到清楚区间后以 5～10 细调，每次等镜头停止。它不是毫米焦距，750/414 都不是通用推荐值。 |
| `exposure_time_absolute` 曝光 | 数值越大越亮，也越容易拖影。以运动物料验收；现值 80 若拖影，可试 60、40、30。变暗优先增加均匀补光。标准单位 100 µs，80 约为 8 ms。 |
| `white_balance_temperature` 白平衡 | 固定曝光后，用工作面中性灰卡或不过曝白纸。关闭自动白平衡，上下各试 200 找方向，再以约 100 细调，最后检查全部真实颜色。 |
| `gain` 增益 | 先保持低值，通常从 0 开始；曝光受运动限制且补光不足时再小步增加，注意噪声。 |

本机历史范围：对焦 0～1023、曝光 1～10000、白平衡 2800～6500、增益 0～255。
实际范围用下面的 `--list-ctrls-menus` 查看。饱和度先保持 60，其他成像参数先不调。
曝光单位参考 [V4L2 相机控制说明](https://www.kernel.org/doc/html/latest/userspace-api/media/v4l/ext-ctrls-camera.html)。

## 2. 自动调参步骤

**第一步：** 固定机位、工作距离和补光，摆好真实背景与物料，整个过程保持画面内容不动。

**第二步：** 运行，纯终端环境加 `--headless`：

```bash
python3 tools/capture_camera_profile.py \
  --profile competition_locked \
  --settle-seconds 10 \
  --stable-seconds 3 \
  --timeout-seconds 45 \
  --activate
```

每次都会重新开启自动白平衡、曝光和对焦。至少观察 10 秒，最近约 3 秒的控制值和画面都稳定后才锁定；
锁定后再检查稳定性及画面是否突变，每个观察阶段最多 45 秒。

锁前参考取自**本次运行、自动阶段结束前约 3 秒的采样画面**；锁后参考取自关闭自动控制并写入数值后，
跳过最初约 1 秒、随后稳定窗口的采样画面。每帧缩至 160×120，分成 4×4 块，比较窗口平均后的
各块 B/G/R 均值，取最大差值；默认要求不超过 8，同时检查清晰度变化。不是比较物体有没有移动。
场景固定，曝光/白平衡/对焦改变仍能使画面不同。

**第三步：** 看最终结果，不要只看中途的 `stable: true`：

- `CAMERA_PROFILE_CAPTURED` 且 `saved: true`：已保存；`activated: true` 表示已启用该档。
- `CAMERA_PROFILE_FAILED`：未保存新档；程序会尝试恢复运行前的设备参数。
- `image changed after locking`：锁前后画面差异过大。当前 DECXIN 已出现自动回读仍为旧值
  `4200/80/750`、写回后画面改变的现象；若场景确实固定，改用下面的手动步骤，不要靠放宽阈值强行通过。

**第四步：** 成功后重新打开预览（命令见下节），用真实物料检查亮度、清晰度和六色识别。
稳定不代表参数最佳；也不要求背景必须黑白。中性灰卡用于判断白平衡，不能替代真实物料验收。

## 3. 手动调参步骤（本机自动回读异常时使用）

### 第一步：打开预览

```bash
python3 -m jetson_recognition.run live \
  --mode COLOR --scene TURNTABLE --target red \
  --camera-profile competition_locked --show-hsv --show-mask --show-fps
```

保持预览运行。下面的读取、设置、保存命令在**另一个终端**执行。

### 第二步：读取设备状态并关闭自动控制

每个新终端先设置设备变量：

```bash
export CAM="$(python3 -c 'import json; print(json.load(open("config/jetson.json"))["camera"]["device"])')"
v4l2-ctl -d "$CAM" --list-ctrls-menus
v4l2-ctl -d "$CAM" --get-ctrl=white_balance_automatic,auto_exposure,focus_automatic_continuous,white_balance_temperature,exposure_time_absolute,focus_absolute,gain
```

关闭自动控制，任意一条报错先排查，不继续设置：

```bash
v4l2-ctl -d "$CAM" --set-ctrl=white_balance_automatic=0
v4l2-ctl -d "$CAM" --set-ctrl=auto_exposure=1
v4l2-ctl -d "$CAM" --set-ctrl=focus_automatic_continuous=0
```

### 第三步：一次只调一个参数

下面数字是写法示例，替换为你要测试的值；**逐行操作、观察画面，不要一次全改**：

```bash
v4l2-ctl -d "$CAM" --set-ctrl=focus_absolute=750
v4l2-ctl -d "$CAM" --set-ctrl=exposure_time_absolute=80
v4l2-ctl -d "$CAM" --set-ctrl=white_balance_temperature=4200
v4l2-ctl -d "$CAM" --set-ctrl=gain=0
```

按第 1 节的方法判断效果，设置后回读确认。`v4l2-ctl` **只改设备，不保存 JSON**。
不要用 `capture_camera_profile.py --exposure ...` 代替单项微调，它仍会重新运行自动阶段。

### 第四步：把已调好的设备参数保存到 JSON

保持预览运行、停止继续调参，在项目根目录复制执行：

```bash
python3 - <<'PY'
import json
from pathlib import Path
from tools.capture_camera_profile import ALL_CONTROLS, read_controls, save_config

path = Path('config/jetson.json')
config = json.loads(path.read_text(encoding='utf-8'))
camera = config['camera']
values = read_controls(camera['device'], ALL_CONTROLS)
for key, value in {'white_balance_automatic': 0, 'auto_exposure': 1,
                   'focus_automatic_continuous': 0}.items():
    if values[key] != value:
        raise SystemExit('请先关闭自动控制：' + key)
values['_replace_base'] = True
camera.setdefault('v4l2_control_profiles', {})['competition_locked'] = values
camera['v4l2_control_profile'] = 'competition_locked'
print('原配置备份：', save_config(path, config))
print('已保存并启用 competition_locked：', values)
PY
```

此命令只回读并保存，不重新自动采样；同时记录其他成像控制，便于复现。
使用配置中的 `camera.device`，需与预览设备一致。本脚本控制项针对项目的 DECXIN 相机。

### 第五步：重启复核，再调颜色

停止预览，再用第一步的命令重启，确认参数和画面可复现。
依次测试 `red / yellow / blue / green / black / light_blue`，检查亮处、暗处和实际运动状态。
相机固定后才调整 `colors.*.hsv_ranges`；黑色调整 `colors.5.black_threshold`。
以 Mask 主体完整、背景干净、相邻颜色不混淆为准。修改颜色 JSON 后也要重启。

## 4. 调色前的白场归一化（规则取消补光后新增）

现在的颜色检测先做**逐帧白场归一化**：用画面里的亚光白场地估计光源色温与亮度，
把整帧重新曝光到白场 = `color_detection.illumination.canonical_level`（235）。
因此调参时看到、读到的 HSV 都是**归一化之后**的数值，与探测器使用的完全一致：

- 预览窗口在颜色模式下显示归一化后的画面，左下角标注
  `WHITE BALANCED ref=[...] gain=[...] <reason>`；鼠标探针也读该画面。
- 白场必须留在画面里（转盘周围的地面即可），且**不要被削顶**：
  `reason=WHITE_FIELD_CLIPPED` 或 `overexposed_ratio` 偏高时先降低
  `exposure_time_absolute`，让白场落在 200～240。
- 光照变化后不需要重调阈值：换暖光/冷光/遮一半环境光，`round_batch` 应保持一致。
  详细说明与 A/B 命令见 [环境光鲁棒色块识别](环境光鲁棒色块识别.md)。
- 有了色块级分类（按整块物料的均值颜色判色号）后，`hsv_ranges` 的 `v_min`
  可以放宽一些，只要物料的像素主体能落进区间即可。

### 无补光时的额外三步

1. **先把曝光调到 `exposure_hint=OK`**：看工具输出里的 `illumination.gain`，目标 0.9~1.3。
   gain 到 3 就说明这张图本来就欠曝，此时调 HSV 是在跟噪声搏斗；
   详见 [环境光鲁棒色块识别](环境光鲁棒色块识别.md) 第 5 节。
2. **选模式**：顶层 `lighting.fill_light`，`false`=无补光（本届规则，开白场归一化）、
   `true`=有补光（关归一化）。命令行用 `--fill-light` / `--no-fill-light` 临时切换。
   两种模式的 `v_min` 含义不同，各调一次。
3. **想更准就顺手标定颜色**：窗口里鼠标放到物料上按 `1`~`6`（按色号），六个做完按 `w` 存盘，
   写入 `colors.<id>.prototype_hsv`，同一批物料只需做一次。

形状干扰大时看 `color_detection.geometry.min_mass_ratio`（空心/碎裂色斑）与
`max_aspect_ratio`（细长条），工具的 JSON 会给出每块物料的实测形状指标。
